# ATLAS: Autonomous Triage, Logical Agentic System

Team ClapTac, CodeSplash '26, Theme 3: AI Disaster Response Coordinator.

Open the console and go to **Practice drills**. Start *Ratnapura, Cyclone Ditwah floods, November 2025*,
which replays the real gauge record. Then watch **Overview** and **Map**, approve the public alert under
**Decisions**, and read it in Sinhala, Tamil and English under **Alerts & reports**.

This is a demo: storage resets when the Space restarts. Source and documentation are in the GitHub
repository.
